# OpsFlow Demo — Rizoma

Demo interactiva que muestra cómo **Rizoma** aplica ciencia de datos para optimizar procesos operativos. Basada en un caso real resuelto: **Alimentos Santa Emilia, C.A.**

## Caso de demostración

**Empresa:** Alimentos Santa Emilia, C.A.
**Proceso:** Pedido a despacho
**Sector:** Alimentos y consumo masivo

### Métricas de línea base
- Lead time: 6.8 días
- OTD/OTIF: 62%
- Desperdicio: $13,400 USD/mes

### Resultados (4 semanas)
- Lead time: 5.6 días (-18%)
- OTD/OTIF: 72% (+10pp)
- 75% del plan de mejora ejecutado

## Metodología de 9 pasos

1. **Contexto** — Datos de la empresa y métricas base
2. **Diagnóstico** — Evaluación de madurez operativa (15 preguntas, 5 categorías)
3. **VSM** — Mapa de flujo de valor con tiempos, esperas y retrabajo
4. **Riesgos** — Matriz probabilidad × impacto contextualizada
5. **Desperdicio** — Cuantificación económica del desperdicio operativo
6. **Priorización** — Scoring multi-criterio ponderado de iniciativas
7. **Plan 30 días** — Acciones con responsable, fechas y métricas líder
8. **Seguimiento** — Evolución semanal con detección de tendencias
9. **Reporte** — Resumen ejecutivo consolidado

## Stack

- Next.js + TypeScript + Tailwind CSS v4
- Recharts para visualizaciones
- Datos estáticos (sin base de datos)
- Insights de IA pre-generados (sin costo de API)
